# RC1 — isolated noncanonical pilot

No real election vote totals have been ingested. Reconciling discrepancies never proves misconduct. The registry stores candidates only, not verified source snapshots.

Existing owners: MoneySweep (campaign financing and procurement); Centinelas (early notices); Spiderweb (spatial bridges); TheHub (federation and consumer UI). This repository owns election results versions, reporting-unit interpretations, discrepancies, and review outcomes.

Stable identity keys are mandatory; neither name resemblance nor proximity proves identity. Missing is distinct from zero. Production and hub discovery are explicitly blocked.
